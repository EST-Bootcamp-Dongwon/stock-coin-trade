# ─────────────────────────────────────────────────────────────────
# v3.0 섹터 ETF 레이더 — **Streamlit Community Cloud 가 설치하는 목록이다.**
#
# ★ 왜 루트인가 — 우회로가 없다.
#   Cloud 는 의존성 파일을 ① 엔트리포인트가 있는 디렉터리 → ② 저장소 루트 순으로
#   찾고, **처음 만난 파일 하나만** 쓴다("only the first file encountered will be
#   used" — 공식 문서). 엔트리포인트가 루트 `streamlit_app.py` 라 두 후보가 한 곳으로
#   붕괴하고, 배포 UI 에 의존성 파일 경로를 지정하는 칸이 없다.
#
#   인식 우선순위: `uv.lock` → `Pipfile` → `environment.yml` → **이 파일** →
#   `pyproject.toml`.
#   🔒 `uv.lock` 이 커밋되면 이 파일을 **이긴다.** `.gitignore` 로 막아 뒀다 —
#      로컬에서 uv 를 쓰더라도 커밋하지 마라. 배포가 조용히 다른 목록을 설치한다.
#   ★ `pyproject.toml`(ruff 설정용)은 이 파일보다 **뒤**라 추가해도 안전하다.
#
# ★ Vercel(v2.0) 의 slim 목록과 그 근거 주석은 **`api/requirements.txt`** 로 옮겼다
#   (2026-09-11 · 되살리는 절차는 `VERCEL.md` 0장 · → ADR-SC-0008 ②).
# ★ v2.0 개발용은 `backend/requirements.txt` 다.
#
# 🔒 위 두 파일과 **버전 핀을 맞추지 않는다.** 다른 앱·다른 런타임이다.
#    맞추려 들면 v3.0 이 동결된 v2.0 에 발목을 잡힌다.
# 🔒 이 파일을 `backend/.venv` 에 설치하지 않는다. **루트 `.venv` 를 따로 쓴다.**
#    `backend/.venv` 에는 pykrx·fastembed 가 끌고 온 pandas·numpy 가 이미 있어,
#    섞으면 동결 회귀(`manage.py test`)가 무너진다.
#
# ★ **필요한 마일스톤에서 한 줄씩 추가한다.** requirements 가 바뀌면 Cloud 가 환경을
#   다시 만들고, 안 쓰는 패키지는 메모리 2.7GB 한도를 미리 깎는다.
#   (예정: `requests` M3 · `PyYAML` M4 · `huggingface_hub` M6 · 차트 M8.
#    pandas·numpy·pyarrow 는 streamlit 이 이미 끌고 온다 — 따로 적지 않는다)
#
# 🔴 `pykrx` 를 이 파일에 넣지 않는다. KRX FAQ 가 이름을 지목해 IP 차단을 경고한다
#    (→ `AGENTS.md` 3장 제약 · 확정 사실 V3).
#
# Python 버전은 파일이 아니라 **배포 UI(Advanced settings)** 에서 고른다.
# 기본값이 3.12 이고, `runtime.txt`·`.python-version` 은 Cloud 가 읽지 않는다.
# 🔴 배포할 때 **3.12 를 눌러 확인한다** — 공식 문서가 "Python itself can't be
#    changed after deployment" 라고 못박았고, 바꾸려면 **앱을 삭제하고 재배포**해야
#    한다. 한 번에 맞게 고르는 것이 M2 의 실제 작업이다.
# ─────────────────────────────────────────────────────────────────

# Cloud 에 streamlit 이 선설치돼 있으나("You don't strictly need to include
# `streamlit` unless you want to pin or restrict the version") 버전이 **통보 없이**
# 올라가고 위젯 API 는 마이너에서 바뀐다. "언제 돌려도 같은 답"을 요구하는 규약
# (`AGENTS.md` 5장) 때문에 핀을 박는다 — 로컬 `.venv`(Python 3.12.3)에 설치해
# 실제로 띄워 확인한 버전과 같다.
# 🔒 마일스톤 경계(M8 · M14)에서 핀을 갱신한다. 보안 패치가 자동으로 오지 않는다.
