## 결정

### ① 서버는 링크를 부르지 않는다 — SSRF 표면 0 (사용자 결정)

링크는 **저장하고 `<a>` 로 그릴 뿐**이다. 누르면 그 팀원의 브라우저가 연다. 제목 미리보기가 없다.

- SSRF 는 서버가 요청을 보낼 때만 생긴다. 부르지 않으면 표면이 없다
- 팀원이 붙일 링크의 상당수가 네이버 뉴스다. 서버가 긁으면 **V7(봇 자동 수집 금지)의 봇**이 된다
- 제대로 된 가드는 연결 시점 IP 고정 · 리다이렉트 차단 · 바이트 상한 · Content-Type 까지다.
  얻는 것(제목 한 줄)에 비해 크고, 새 의존 없이 짜기 어렵다

🔒 **`links.normalize_link` 는 SSRF 가드가 아니다.** 이름을 `is_public_url` 로 두지 않았다 —
그 이름은 지키지 못하는 약속을 한다(DNS 가 공인 도메인에 사설 IP 를 줄 수 있다). 미리보기를
붙이는 날에는 **연결 시점 검사를 따로 설계**한다. 원장 · 화면 계층에 네트워크 import 가
생기면 정적 검사가 깨져 그날을 드러낸다.

받는 규칙 — **팀원 브라우저가 어디로 가나**를 막는다:

| 규칙 | 막는 것 |
|---|---|
| `https` 만 | `javascript:` · `data:` · 평문 http |
| `@`(userinfo) 거부 | `https://naver.com@evil.example/` — 보이는 곳과 가는 곳이 다르다 |
| IP 리터럴 · 숫자로 끝나는 호스트 거부 | `https://192.168.0.1/` · 브라우저가 IPv4 로 읽는 `0x7f.1` · `2130706433` |
| 내부망 이름 거부 | `localhost` · `local` · `internal` · `lan` · `home` · `corp` · `test` · `example` · `invalid` · `onion` · `arpa` |
| 443 외 포트 · 공백 · 제어문자 거부 | 브라우저가 지우고 읽는 탭 · 줄바꿈 |
| 국제화 도메인 → 퓨니코드 | 동형문자가 드러난다 |
| 퓨니코드를 되돌렸을 때 다른 이름이면 거부 | 파이썬 IDNA(2003)가 `faß.de` → `fass.de`, 한 점 리더 → `.` 로 **이름을 바꿔** 브라우저와 다른 곳이 된다 |
| 500자 · 코멘트당 3개 · 같은 링크는 하나 | Y7 의 바이트 계산 |

🔒 굳힌 모양이 저장 모양이고 **멱등**이다. 표시는 **주소 자체**다 — `[제목](url)` 처럼
이름을 붙이게 하지 않는다. `rel="noopener noreferrer nofollow"` · `target="_blank"`.
🔴 길면 **경로만** 자르고 **호스트는 자르지 않는다** — `n.news.naver.com.….attacker.com` 을 앞에서
자르면 `naver.com` 만 보인다.

⚠️ **DNS 를 부르지 않는 검사의 한계** — 공인 도메인이 사설 IP 로 풀리는 이름(`127.0.0.1.nip.io` ·
`localtest.me`)은 막지 못한다. 보이는 주소와 가는 주소가 같으므로 기만은 아니다.

### ② '섹터 확정' 페이지를 없애고 랭킹의 모달로 확정한다 (사용자 결정)

| 자리 | 무엇 |
|---|---|
| **섹터 랭킹** "왜 이 점수인가" 아래 **우리 조** | 조원이 이 섹터에 붙인 근거 · **[핵심 섹터로 확정]** 모달 · **[근거 붙이기]** 모달 |
| **조** | 우리 조의 핵심 섹터 · 그 근거 · 조원 근거 · **[확정 되돌리기]** 모달 · 이 조의 기록(펼침) |

- 내비게이션이 4 → **3** 이다(섹터 랭킹 · 조 · 읽는 법)
- 🔴 **확정 모달 안에 근거 한 벌을 다시 그린다.** 모달이 랭킹을 가리므로, 사유를 쓰는 동안
  근거가 안 보이면 사유 칸이 "1위라서" 로 채워진다. 같은 함수(`evidence.render_evidence`)다
- 🔒 이미 확정했으면 **다른 섹터의 확정 버튼이 없다.** 조 페이지에서 되돌린 뒤 확정한다 —
  되돌린 사유가 운용보고서의 '포폴 변경 사유' 가 된다
- 🔒 모달은 **플래그로 연다**(Y8). 닫힌 뒤의 성공 문장은 세션에 한 번 남긴다(모달 안의
  `st.success` 는 다시 돌면 사라진다)
- 🔒 원장에 닿지 못해도 **랭킹은 산다** — "우리 조" 칸만 오류를 말한다

### ③ 링크 검사는 쓸 때와 **읽을 때** 두 번 한다 (Y5)

- 쓰기 — `events.comment_posted` 가 굳힌 링크만 담는다
- 읽기 — `fold` 가 원장의 링크를 **다시 굳혀 보고 같을 때만** `Comment.links` 에 담는다.
  아니면 버리되 **`anomalies` 로 올린다**(조용히 버리지 않는다)
- 원장의 `sector_id` 도 읽을 때 식별자 규칙으로 거른다 — 어긋난 확정은 반영하지 않고, 어긋난
  코멘트는 어느 섹터에도 붙이지 않는다. 둘 다 `anomalies` 다(그 글자가 모달 제목 · 목록으로 흘러가지 않게)

### ④ 사람이 쓴 글은 **그릴 때** 이스케이프한다 (Y3 · Y4 · 사용자 결정으로 #8 에 포함)

| 헬퍼 | 어디에 | 무엇을 |
|---|---|---|
| `theme.user_block` | 여러 줄 글(사유 · 근거 · 기록) | `html.escape` + **줄바꿈 → `<br>` 로 한 줄**. CommonMark HTML 블록은 빈 줄에서 끝나 그 뒤가 마크다운으로 새므로(`![](…)` 추적 이미지가 되살아난다) 한 줄이어야 한다 |
| `theme.esc` + `html_line` | 한 줄 자리(이름 · 날짜 줄 · 원장에서 온 섹터 id · anomaly 문장) | `html.escape` 후 **줄 전체를 `<div>` HTML 블록**으로. 🔴 마크다운 역슬래시 이스케이프는 쓰지 않는다 — GFM 자동 링크를 못 막는다(Y9) |
| `theme.links_block` | 코멘트 링크 | 주소 표시 · `href` 이스케이프 · `rel` |
| `theme.failure` | 저장소 · 원장 오류 | 요약은 `st.error`, 오류 문장(원장의 `event_id` 가 섞일 수 있다)은 HTML 블록 |

대상은 조 이름 · 참가자 이름 · 사유 · 근거 · 원장에서 온 섹터 id(RPC 로 아무 글자나 들어온다) ·
anomaly 문장 · 저장소 오류 문장이다. `sectors.yaml` 에서 온 글은 커밋된 설정이라 대상이 아니다.

🔒 **위젯 라벨 · 모달 제목 · `st.success` · `st.error` 는 마크다운이다 — 사람 글을 넣지 않는다.**
그래서 성공 문구에서 조 이름을 뺐고("참가했다."), 보관하기 라벨은 "이 조 보관하기" 이며, 되돌리기
모달 제목은 `sectors.yaml` 에 있는 섹터일 때만 이름을 쓴다. 예외는 하나다 — 이벤트를 만들지 못한
이유(`st.error`)에는 **방금 그 사람이 입력한 글**이 섞이고, 그 사람의 화면에만 그려진다.

### ⑤ 제어문자는 쓰기 길에서 거부하고, payload 상한은 앱이 먼저 잰다 (Y6)

- `events._require_prose` — 탭 · 줄바꿈 외의 C0 · DEL 을 거부한다. 이름 칸은 줄바꿈도.
  🔒 **읽기 길(`parse_event`)에는 두지 않는다** — 옛 원장 한 줄이 원장 전체를 죽인다
- `events.PAYLOAD_MAX_BYTES = 16384` — 마이그레이션의 CHECK 와 **같은 수**이고 테스트가 두 파일을
  대조한다. `payload_bytes` 는 jsonb 텍스트 규칙(`", "` · `": "` · UTF-8 · `\uXXXX`)으로 잰다.
  ⚠️ **실DB 와 바이트를 대조하지는 않았다** — 정상 입력은 상한에서 2.8KB 떨어져 있다(Y7)
- 🔒 링크가 없는 코멘트는 `links` 칸을 **만들지 않는다** — id 가 #8 이전과 같다

### 대가 — 숨기지 않고 적는다

- 🔴 **XSS 판단은 번들 근거다**(Y3). 실브라우저 재현이 없다. 이스케이프는 재현 여부와 무관하게
  옳은 방향이라 먼저 했고, **Streamlit 핀을 올릴 때 번들을 다시 본다**
- ⚠️ 모달의 **X · 바깥 클릭(`on_dismiss`)** 은 AppTest 로 밟을 수 없다 — 브라우저에서 한 번 확인한다
- ⚠️ **bidi 제어문자(U+202E 등)는 거르지 않는다.** 이름의 글자 순서를 뒤집어 보이게 할 수 있다.
  조 7개 규모에서 우선순위가 낮다 — 필요해지면 `_CONTROL_RE` 에 더한다
- 🔴 **리뷰가 드러낸 기존 문제 — 고치지 않았다(#8 범위 밖).** `workspace_append` 는 `event_id` 를
  다시 계산하지 않는다. passcode 를 가진 사람이 내용과 어긋난 id 를 한 줄 쓰면 `parse_event` 가
  던져 **모든 조의 원장 읽기가 멈추고**, append-only 트리거라 지울 수도 없다. 화면은 이제 그 오류를
  HTML 블록으로 그려 이미지 삽입까지는 막지만 읽기 중단은 그대로다 → `세션-시작-프롬프트.md` 4.5
