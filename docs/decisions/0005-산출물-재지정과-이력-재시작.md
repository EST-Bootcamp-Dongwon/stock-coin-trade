# ADR-SC-0005 — 산출물을 ETF 섹터 분석 대시보드로 재지정하고 이력을 재시작한다

- **상태**: 채택

- **관련**: [ADR-SC-0001](0001-fork-계보-유지.md) **폐기** · [ADR-SC-0002](0002-체결엔진-원본과-이식.md) **폐기** ·
  [ADR-SC-0006](0006-krx-데이터-제3자-제공-금지.md) · [ADR-SC-0008](0008-배포-streamlit-전환과-원격-재구성.md)

## 맥락

이 저장소는 강사님 원본 `edumgt/stock-coin-trade` 의 fork 로 출발해
v1.0(Flask) → v2.0(Django 모의투자 플랫폼)으로 자라 왔다.

그런데 **목적이 바뀌었다.** 키움증권 모의투자 대회(팀 7명 · 약 3개월)를 앞두고 필요한 것은
"자체 모의투자 플랫폼"이 아니라 **"지금 어느 섹터가 유망한가를 근거와 함께 판단하는 도구"**다.
자체 체결 엔진을 만들 이유가 없다 — 체결은 키움이 한다.

동시에 공개 쇼케이스용으로 `github.com/devlee328288/stock-coin-trade` 에 미러링하려 하는데,
현재 이력이 그것을 가로막는다.

| 걸림돌 | 내용 |
| --- | --- |
| 강사님 시크릿 | `k8s/base/secret.yaml` · `k8s/eks/secret.yaml` 에 `CMC_API_KEY: 89a4ffe3-…` 와 DB 비밀번호 4종. 커밋 `a33bddd`·`97d76aaf`·`e0e6f1de`·`10de40a5` |
| 라이선스 미확정 | 원본에 LICENSE 가 없어 재배포 허가가 없다 ([NOTICE.md](../../NOTICE.md)) |
| 타인 커밋 | 94커밋 중 76건이 강사님·Copilot·타인. 사용자 커밋은 18건 |

워킹트리에서 파일을 지워도 **이력에서는 사라지지 않는다.** `git log -p` 로 나오고
GitHub 웹에서 과거 커밋을 열면 그대로 보인다.

## 결정

**① 이 저장소의 산출물을 "섹터 ETF 레이더"(Streamlit 대시보드)로 재지정한다.**

**② 이력을 orphan 으로 재시작한다.** 강사님 코드는 새 이력에 담지 않는다.

**③ 본인이 쓴 v2.0 Django `backend/`(26,597줄 · 테스트 384건)는 담되 동결한다.**

- 동결의 뜻: **개발하지 않으나 `cd backend && .venv/bin/pytest` 23건은 계속 통과해야 한다.**
- 해제 시점은 대회 종료 후에 다시 판단한다.

**④ ADR-SC-0001 과 ADR-SC-0002 를 폐기한다.**

- 0001(fork 계보 유지)은 "강사님 코드를 받을 능력"을 지키기 위한 것이었다.
  그 능력을 **의도적으로 버린다.**
- 0002(체결 엔진 원본)는 `trading/services.py` 를 `quant-core` 로 이식하기 위한 것이었다.
  새 목적에 체결 엔진이 없다. 코드는 `backend/` 에 동결된 채 남으므로 필요하면 다시 꺼낸다.
  (2026-09-15 — `quant-core` 자체가 개발하지 않기로 해 삭제됐다. 이식이 필요 없다는
  이때의 판단이 결과적으로 다시 확인된 셈이다.)

## 근거

**이력 재시작이 `filter-repo` 선별 제거보다 낫다.** 강사님 경로만 골라내도
① 76개 커밋이 빈 껍데기로 남거나 사라져 이력이 어색해지고 ② 커밋 작성자 이메일은 그대로 남으며
③ `k8s/secret.yaml` 은 이미 지워진 다른 경로라 따로 지정해야 하고 ④ SHA 는 똑같이 전부 바뀐다.
**같은 비용이면 깨끗한 한 커밋이 낫다.**

**강사님 코드를 빼면 세 문제가 동시에 사라진다** — 시크릿(이력 없음), 라이선스 미확정
(원본 코드 미포함), 타인 커밋 이메일. 재사용하려던 코드
(`_fetch_naver_chart`·`krx_news`·`_is_public_url`)는 **약관 조사 결과 어차피 쓸 수 없거나**
(→ [ADR-SC-0006](0006-krx-데이터-제3자-제공-금지.md)) 새로 쓰는 편이 나은 것들이었다.

## 결과

- ✅ 공개 미러가 **온전히 본인 작업물**이 된다. 라이선스·시크릿 문제가 없다.
- ✅ 파일을 자유롭게 배치할 수 있다. ADR-SC-0001 의 제약이 사라졌다.
- ⚠️ **되돌릴 수 없다.** bundle 백업과 `verify` 를 orphan 전에 반드시 한다.
- ⚠️ 본인의 v2.0 개발 커밋 18건의 **이력**이 사라진다(코드는 남는다). bundle 에는 있다.
- ⚠️ 부모 모노레포 `projects/` 서브모듈이 `9b90f49` 를 가리키고 있다.
  **`projects` → 부모 순서로 새 gitlink 를 커밋하지 않으면 서브모듈이 깨진다.**
- ⚠️ `backend/` 가 방치돼 이 ADR 이 거짓말이 되지 않도록,
  **M1·M7·M14 의 완료 조건에 "골든 23건 통과"를 넣는다.**
