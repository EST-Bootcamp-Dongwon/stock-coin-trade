- **날짜**: 2026-09-18
- **관련**: M9c · [ADR-SC-0014](0014-점수-재현성과-가중치-슬라이더의-경계.md) ③④⑤ ·
  [ADR-SC-0012](0012-근거-첨부와-확정-모달.md) ④ · [ADR-SC-0013](0013-내부-에이전트-엔진-layer-a.md) ④-1 ·

- **닫는 것**: ADR-SC-0014 가 남긴 M9c(URL 공유 · 대분류별 순위 분포)
- **정정하는 것**: ADR-SC-0014 "남긴 것" 절의 괄호 설명 — 아래 **I** 참조

## 맥락

M9c 는 두 가지다 — 팀원이 "내가 본 화면" 을 링크로 보내는 것, 그리고 "어느 대분류가
전반적으로 강한가" 에 **대분류 점수를 만들지 않고** 답하는 것.

착수 전에 플랫폼 동작을 실측했다. 설계가 두 번 뒤집혔다.

| # | 사실 (streamlit 1.63.0) | 어떻게 확인했나 |
|---|---|---|
| **A** | `st.query_params` 쓰기는 **rerun 을 유발하지 않는다** | `QueryParams.__setitem__` → `_send_query_param_msg` · AppTest 프로브 |
| **B** | 🔴 프런트엔드는 **`window.history.pushState`** 로 URL 을 바꾼다 — 쓸 때마다 히스토리가 한 건 쌓인다 | 번들 `index.*.js` 의 `handlePageInfoChanged` |
| **C** | `AppTest.query_params` 는 인스턴스 속성 — 넣고 run, run 뒤 읽기 둘 다 된다 | `app_test.py` · 왕복 프로브 |
| **D** | 다중값 파라미터(`?gics=A&gics=B`)는 **`get_all` 로만** 온다. 매핑 접근은 마지막 값으로 접는다 | `QueryParams.__getitem__` 이 `value[-1]` |
| **E** | 🔴 `st.context.url` 은 AppTest 에서 **`None`** | 프로브 |
| **F** | 🔴 `selectbox` 는 options 밖 세션값을 **조용히 `options[0]` 으로 치환**하고 세션값까지 덮는다 | 프로브 |
| **G** | 🔴 `multiselect` 는 options 밖 항목을 **조용히 버린다** | 프로브 |

| **I** | 🔴 `bind="query-params"` 의 URL 값은 **`format_func` 이 만든 표시 문자열**이다 — `?rank_profile=모멘텀 55/25/15/5` · `?rank_gics=소재`. 내부 id 를 넣으면 거부된다 | 프로브 ②③ |
| **J** | 🔴 `bind` 는 잘못된 값을 **조용히 지운다** | 프로브 ④ · `session_state._clear_url_param` |
| **K** | 🔴 그래서 `bind` 위에 "무시했다" 보고를 덧붙일 수 **없다** — 위젯 등록이 파라미터를 먼저 지워 사용자 코드가 원본을 못 본다 | 프로브 ③④ |
| **L** | 🔴 `str.isdigit()` 은 `int()` 와 **다른 집합**이다 — `"²".isdigit()` 은 `True` 인데 `int("²")` 는 던진다. `"٣٥"` 는 `isdecimal()` 까지 `True` 이고 `int` 가 35 를 준다. 파이썬 3.12 는 4300자리 초과 변환을 막는다 | 직접 실행 |
| **M** | 🔴 `len==8 and isdigit()` 은 날짜 검증이 아니다 — `"00000000"`·`"٣٥٦٧٨٩٠١"`·`"２０２６０９０９"` 가 전부 통과한다 | 직접 실행 |

**I 가 ADR-SC-0014 의 괄호 설명을 정정한다.** 거기에는 *"Streamlit selectbox 는 options 밖
값을 그대로 돌려주고 `Names.sector_full` 은 모르는 코드를 그대로 준다 → 임의 문자열이 패널
제목 마크다운에 들어간다"* 고 적혀 있다. **1.63.0 에서는 그렇지 않다**(F·G) — 위험은 마크다운
주입이 아니라 **조용한 대체**다. 즉 `bind` 를 기각한 이유(J)와 **같은 종류**이고, 우리 화이트리스트와
"무시했다" 보고는 그 침묵을 깨기 위해 여전히 필요하다.

## 결정

### ① URL 은 **버튼을 누를 때만** 쓴다. 자동 갱신하지 않는다

```python
if st.button("🔗 이 화면을 링크로 만들기"):
    st.query_params.from_dict(share.encode(current))
```

처음 설계는 "위젯 값이 바뀔 때마다 URL 을 다시 쓴다" 였다. 근거는 *"주소창이 거짓이면
팀원이 그것을 복사한다"* 였고 그 자체는 맞다. 그런데 **사실 B·H 때문에 그 약속을
이 플랫폼에서 지킬 수 없다** —

- 뒤로가기를 누르면 프런트엔드가 보내는 queryString 은 **우리가 마지막에 쓴 값**이고
  주소창의 값이 아니다(H). 백엔드는 어긋남을 **알 방법이 없다.**
- 히스토리 비용이 "상태 변경당 1건" 이 아니라 **클릭당 1건**이다(B). 섹터를 21개
  훑으면 21건이 쌓여 팀원이 뒤로가기로 앱을 떠날 수 없다.

🔒 **만들 수 없는 것을 약속하면 공유 기능이 거짓말을 한다.** 그래서 추적한다고
가르치지 않는다 — 주소창은 버튼을 누른 그 순간에만 화면과 같고, 버튼 문구가 그
계약을 말한다. 정상 사용 중 pushState 는 **0건**이다.

부수 효과로 셋이 정리됐다 — 사실 E 가 무해해지고(절대 URL 을 안 만든다), 쓰기 지점이
하나가 되어 조기 return 경로의 어긋남이 사라지고, "값이 안 바뀌면 안 쓴다" 를 증명해야
하는 **무력한 테스트**가 필요 없어진다.

### ② `bind="query-params"` 를 쓰지 않는다 — 실측 근거 셋

I·J·K. 특히 **I 가 단독으로 기각시킨다**: URL 계약이 `explain.py` 의 문구에 묶이고,
라벨 한 글자를 고치면 팀에 뿌린 링크가 전부 죽는다. AGENTS.md 4장이 "문구의 정본은
`explain.py`" 라고 정해 둔 것과 정면으로 충돌한다.

⚠️ **대가를 적어 둔다** — 내장 바인딩은 `history.replaceState` 를 쓰고 쓰기 전에
**실제 주소창**과 비교한다. 즉 히스토리·뒤로가기 문제를 이미 풀어 두었다. 우리는
그것을 포기하는 대신 ① 로 히스토리를 아예 건드리지 않는 길을 골랐다.

### ③ 파라미터 표 — **화이트리스트가 전부다**

| 키 | 모양 | 화이트리스트 |
|---|---|---|
| `profile` | `balanced` | `view.PROFILES` |
| `w` | `M35-F30-B20-V15` | ASCII 10진 · 3자리 이하 · 0~`MAX_WEIGHT` · **축 넷 전부-또는-무효** |
| `gics` | 반복 파라미터 | 그날 프레임에 실재하는 대분류 id |
| `illiquid` · `single` | `1` / `0` | 그 둘만. 없으면 꺼짐 |
| `sector` | `steel` | 그날 프레임에 실재 **그리고** 필터에 안 가려짐 |
| `as_of` | `20260910` | `strptime("%Y%m%d")` 로 **실재하는 날짜** |

- 🔒 `profile` 은 **항상** 넣는다. 빼면 "기본 프리셋" 이라는 뜻이 되고, 나중에 기본을
  바꾸는 순간 옛 링크의 의미가 조용히 변한다. 나머지는 기본값이면 뺀다.
- 🔒 구분자를 `-` 로 골랐다 — `:`·`,` 는 `urlencode` 가 `%3A`·`%2C` 로 바꿔 링크가 읽히지 않는다.
- 🔒 축 글자(`M`·`F`…)를 값에 함께 담는다 — 순서만 적으면 손으로 쓴 링크의 **순서 착오를
  검출할 수 없다.**
- 🔒 `w` 는 **전부-또는-무효**다. 일부만 받으면 나머지를 어디선가 채워야 하고 그것이 곧
  값을 지어내기다(제약 8).
- 🔒 그러나 **네 축 전부 0 은 받는다.** 슬라이더로 도달 가능한 상태이고 그때 화면은 오류를
  내고 프리셋으로 그린다. 파싱이 거절하면 링크가 그 화면을 재현하지 못한다. 전부-0 판정은
  화면(`Weighting.of`)이 한다 — 그래서 `Share` 가 `custom` 과 `weights` 를 **따로** 든다.

### ④ 규칙 한 줄 — **URL 은 위젯의 초기값만 정한다**

화면이 실제로 쓰는 것만 화면이 말한다. 그래서 쓸 수 없는 파라미터를 기본값으로 두는 것은
값을 지어내기가 **아니다** — 캡션이 실제로 쓰는 가중치와 필터를 적는다(`weighting_label` ·
"N개 표시"). 반대로 **기준일은 지어낼 수 없다** — 링크의 `as_of` 가 지금 표와 다르면
화면이 **방향까지** 말한다(내 표가 더 옛날일 수 있다 — `load_scores` 의 HF→로컬 폴백).

보고 규칙도 이 한 줄에서 나온다 —

- **아는 키**인데 못 쓴 것은 **이름만** 말한다(`` `profile` `` 처럼).
- **모르는 키**는 **개수만** 센다 — 키 이름도 외부 글이고 `st.warning` 은 마크다운을 읽는다.
- **필터에 가려진 섹터**는 **이름을 말한다.** 그 id 는 우리 프레임에서 왔고(ADR-SC-0012 ④ 가
  "커밋된 설정에서 온 글" 을 대상에서 뺀다), 말해야 링크가 목적을 잃지 않는다.
- 🔒 `Parsed` 의 필드를 `Literal`·`int`·`bool` 로 좁혀 **화면이 외부 글자를 그릴 수 없게** 한다.

### ⑤ 적용은 **첫 로드에만.** 플래그는 **무조건** 세운다

한때 "프레임 때문에 무시된 것이 있으면 플래그를 세우지 않는다" 로 두었다. 드문 경우를
지키려는 조건이었다 — `load_scores` 캐시 TTL(300초)·HF→로컬 폴백으로 프레임이 세션
안에서 바뀌면, 옛 파생본에 없던 섹터가 되살아나야 한다.

🔴 **그 조건이 `?sector=<없는id>` 한 줄로 그 세션의 모든 위젯을 영구히 잠갔다.**
플래그가 없으니 매 rerun URL 이 위젯 키에 다시 심기고, 라디오·체크박스·멀티셀렉트를
몇 번 눌러도 되돌아온다. 오타 하나, 슬랙에서 잘린 링크 하나, 어제 있던 섹터 id 하나로
충분했다. 더 나쁜 변종은 `hidden_sector` 경로다 — 화면이 "필터를 풀면 나온다" 고
**불가능한 행동을 지시한다**(필터가 매 rerun 다시 켜진다).

🔒 그래서 플래그는 무조건 선다. 드문 경우의 탈출구는 **새로고침**이다 — 링크는 주소창에
그대로 있고 새 세션에서 신선한 프레임에 대고 다시 판정된다. **잠긴 위젯에는 탈출구가 없다.**
드문 것을 흔한 것보다 앞세우지 않는다.

🔒 심는 것은 **모든 위젯보다 앞**이다. `rank_detail` 까지 여기서 심으므로 가려짐 판정에
쓰는 `keep` 은 `view.visible_ids`(순수 함수)로 **위젯 없이** 낸다 — 그러면 정적 검사
(`test_위젯을_그린_뒤에_session_state_를_쓰지_않는다`)의 허용 사유가 한 줄로 정직해진다.

### ⑥ 대분류는 **순위 목록**이다. 요약 통계를 만들지 않는다

ADR-SC-0014 ⑤ 가 대분류 롤업 **점수**를 금지했다(매매 단위가 아니다). 분포는 그 금지를
피하는 대안이지만, 평균·중위를 두면 **점수처럼 읽혀** 같은 자리로 미끄러진다. 사실 O 에서
n≤7 이라 요약값이 정보를 늘리지도 않는다.

`소재 2개 — 1 · 2` 한 줄이 곧 결론이다. **목록이 분포다.**

- 🔒 정렬 정본은 **정수 열** `최고순위`다. 목록 문자열로 정렬하면 사전순이 되어 `10` 이 `2` 앞에 온다.
- 🔒 **필터를 따른다** — 표·등수·막대와 같은 규칙이다. 한 화면에서 칸마다 규칙이 다르면
  캡션으로 설명될 차이가 아니다(예외는 `_render_consensus` 하나이고 그 머리주석이 이유를 적는다).
  🔴 그래도 **순위 자체는 그날 21개 횡단면 값**이다. 행을 숨길 뿐 다시 매기지 않는다.
- 🔒 **가중치를 따른다** — 표·막대와 같은 숫자를 말해야 한다(ADR-SC-0014 ④).
- 🔒 순위 없는 섹터를 **최악 순위로 취급하지 않는다.** `순위없음` 칸에 센다(ADR-SC-0007).
- 🔒 대분류 없는 섹터를 **숨기지 않는다.** `미분류` 로 드러낸다 — 사실 N 의 `dropna` 기본값이
  그 섹터를 조용히 버려 "테마수 합계 = 보이는 섹터 수" 를 깼다(3개 중 2개).
- 🔒 **화면 이름으로 묶는다**(사실 N 의 튜플 키를 피하려 `Series` 로 넘긴다) — 그러면 색인이
  구조적으로 유일하다. 서로 다른 id 가 같은 한국어 이름을 갖는 것은 `sector_master._check_ids`
  가 막는다(이번에 대분류까지 검사하게 넓혔다 — 섹터만 보고 있었다).
- 🔒 에이전트는 이 표를 **읽지 않는다** — 장부가 대조할 저장 열이 없다(ADR-SC-0013 ④-1).

## 한계 — 알고도 안 고치는 것

- 🔴 **파라미터 1000개 초과 · 쿼리 512Ki 초과면 Streamlit 이 쿼리를 통째로 지운다**
  (`sanitize_query_string`). 그러면 "파라미터가 없다" 와 구별할 수 없어 **아무 말도 못 한다** —
  `bind` 를 기각한 그 침묵이 이 경계에는 우리 쪽에도 있다. AppTest 는 그 경로를 밟지 못한다.
- `DataUnavailable` 화면에서는 링크 보고를 하지 않는다. 화이트리스트가 프레임에 의존해서
  (`gics_ids`·`sector_ids`·`as_of`) 프레임 없이 파싱하면 멀쩡한 `gics`·`sector` 까지 "못 썼다"
  고 말한다. **틀린 보고보다 침묵이 낫고**, 플래그를 세우지 않았으므로 다음 성공 로드에서
  제대로 적용된다.
- `sectors.yaml` 의 `name_ko` 에 문자 제한이 없다. 누군가 `name_ko: "[철강](javascript:…)"` 을
  커밋하면 경고 문장에서 마크다운으로 그려진다 — 설정 리뷰에 의존하는 잔여 위험이다.

## 대안과 기각

| 대안 | 왜 아닌가 |
|---|---|
| `bind="query-params"` | ② — 사실 I·J·K. URL 이 한국어 표시 문구에 묶인다 |
| 위젯이 바뀔 때마다 URL 갱신 | ① — 사실 B·H. 뒤로가기 뒤 주소창이 거짓이 되는 것을 백엔드가 알 수 없고, 클릭마다 히스토리가 쌓인다 |
| "이 화면 링크" 복사칸(`st.code`) | 사실 E — `st.context.url` 이 AppTest 에서 `None` 이라 절대 URL 을 만들 수 없고 검증도 못 한다. 주소창이 곧 링크다 |
| `sector` 를 URL 에서 빼기 | "이 섹터의 근거를 보라" 가 팀이 가장 공유하고 싶은 것이다. ① 로 히스토리 비용이 사라져 담을 수 있게 됐다 |
| 대분류 평균·중위 순위 | ⑥ — 점수처럼 읽혀 ADR-SC-0014 ⑤ 로 미끄러진다. n≤7 에서 정보도 늘지 않는다 |
| 대분류 분포가 필터를 무시 | ⑥ — 한 화면에 규칙이 셋이 된다 |
| `as_of` 를 담지 않기 | ④ — 링크가 하루 뒤 다른 것을 뜻한다. 옛 날짜를 그릴 수는 없으니 **말한다** |
| 옛 기준일의 표를 그리기 | 그럴 데이터 경로가 없다(화면은 언제나 `latest_frame`). 만들려면 M10 이후다 |
