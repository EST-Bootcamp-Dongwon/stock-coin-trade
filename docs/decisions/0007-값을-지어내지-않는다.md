# ADR-SC-0007 — 값을 지어내지 않는다 (취득 실패는 예외이거나 "없음" 표시다)

- **상태**: 채택
- **날짜**: 2026-09-11
- **관련**: [ADR-SC-0005](0005-산출물-재지정과-이력-재시작.md) · [ADR-SC-0006](0006-krx-데이터-제3자-제공-금지.md)

## 맥락

사용자가 이 프로젝트에 건 요구 중 하나가 **"환각 없이 정확한 정보"** 다.
보통 이 말은 LLM 을 겨냥하지만, 이 프로젝트에서 값을 지어내는 주체는 LLM 이 아니다.
**폴백 코드다.**

강사님 원본(`edumgt/stock-coin-trade` 의 `python-stock-backend/stock_market.py`)은
시세 취득이 실패하면 `_simulated_price()` 로 **조용히 결정론적 가짜 값을 돌려준다.**
데모 웹앱에서는 화면이 안 깨지니 합리적인 선택이었다.

분석 도구에서는 정반대다. **가짜 숫자로 투자 판단이 나간다.** 더 나쁜 것은 그 값이
에러를 내지 않아 아무도 모른다는 점이다. "데이터가 없다"보다 **"틀린 데이터가 있다"가 훨씬 나쁘다.**

이 저장소의 v2.0 README 에도 "데모의 시세는 전부 시뮬레이션 값입니다"라는 문장이 있다.
그것은 v2.0 에 대한 참인 서술이고, v3.0 은 그것을 **금지한다.**

## 결정

**데이터 취득이 실패하면 예외를 던지거나 "없음"으로 명시 표시한다.
폴백·기본값·전일값 채우기·평균 대입을 하지 않는다.**

다섯 겹으로 강제한다. 한 겹이 뚫려도 다음이 잡는다.

| 겹 | 장치 |
| --- | --- |
| **① 타입** | `ExternalDataError(message, hint=)` — 성공과 실패가 같은 타입으로 나오지 않는다. `hint` 에는 *운영자가 무엇을 해야 하는지*를 적는다 |
| **② 반환 계약** | `Optional` 을 쓰지 않는다. 값이 없으면 예외이거나 `is_partial=True` + 해당 칸 `NaN`. 0·전일값·평균으로 채우지 않는다 |
| **③ 업로드 게이트** | `batch/publish.py` 가 검사기를 **스스로** 돌린다 — 가격 ≤ 0 / 영업일 아님 / `(bas_dd, sector_id)` 중복 / 일간 ±30% 초과면 실패. 🔒 **검사기 파일이 없으면 "통과"가 아니라 "실패"다** |
| **④ 렌더** | `missing_cell()` 한 곳에서만 그린다. `is_partial`·`stale` 은 회색 `—`. **숫자를 아예 그리지 않는다** |
| **⑤ 정적 검사** | `test_no_silent_fallback` — `sector/` 에 `except Exception: pass` 나 근거 없는 `return None` 이 0건. ruff `BLE001`(blind except)을 켠다 |

### 스키마 차원의 금지도 포함한다

- `sector_daily` 에 `is_partial` 칸을 둔다 — **결측을 채우지 않았다는 표시**다.
- `news_item` 에 **본문·요약·감성점수 칸을 만들지 않는다.** 칸이 없으면 채울 수 없다.
- 화면 문구는 `dashboard/explain.py` 의 **템플릿으로만** 만든다. f-string 에 숫자를 끼우는
  것이지 생성이 아니다. 그 파일도 골든 테스트로 고정해 문구 변화가 diff 로 보이게 한다.

## 근거

값을 지어내는 코드는 **버그가 아니라 설계 선택**이라 리뷰에서 잘 걸리지 않는다.
"실패하면 예외"를 규칙으로만 두면 급할 때 반드시 무너진다. 그래서 타입·계약·게이트·렌더·
정적 검사 다섯 지점에 **서로 다른 성격의 장치**를 놓았다.

특히 ③의 *"검사기 파일이 없으면 실패"* 는 의도적이다. 검사기를 지우거나 옮겨서
게이트를 우회하는 경로를 막는다.

④가 한 곳인 것도 의도적이다. 결측 표현이 화면마다 다르면 어떤 `0` 이 진짜 0이고
어떤 `0` 이 "모름"인지 읽는 사람이 구별할 수 없다.

## 결과

- ✅ 화면의 모든 숫자가 실제 취득값이다. `—` 는 "모른다"를 뜻한다.
- ✅ 데이터 공백이 **감춰지지 않고 드러난다.** 페이지 9(데이터 상태)가 공백 목록을 준다.
- ⚠️ 원천이 죽으면 **화면 일부가 비어 보인다.** 이것이 의도다.
  "왜 비었나"는 `hint` 와 페이지 9 가 답한다.
- ⚠️ 강사님 원본의 `_simulated_price()` 계열 코드는 v3.0 이력에 담지 않으므로
  ([ADR-SC-0005](0005-산출물-재지정과-이력-재시작.md)) 격리 자체가 불필요해졌다.
  다만 **비슷한 폴백을 새로 쓰지 않도록** ⑤의 정적 검사를 둔다.
