## 등록하는 법

```bash
cd /path/to/stock-coin-trade
gh auth status && glab auth status          # 🔒 매번 확인 (AGENTS.md 2장)

glab issue create --repo mygithub05253/stock-coin-trade \
  --title "[버그] 가중치 0 인 축이 «기여 0» 으로 그려진다 — 이슈 4 와 같은 결함이 기여 열에 남았다" \
  --label bug --label dashboard --no-editor \
  --description-file "docs/backlog/issues/01-가중치0축의-기여.md"
```

🔒 **한 번에 하나씩, 간격을 두고 올린다.** 연속으로 올리면 다시 막힌다.
등록한 파일은 지우고, 이 표의 «상태» 를 고친다.

⚠️ **본문 안의 `docs/...` 링크는 «GitLab 이슈에서 볼 때» 를 기준으로 썼다**(저장소
루트 기준). 그래서 **이 폴더에서 파일로 열면 그 링크만 깨진다** — 정본은 이슈이고
파일은 등록 대기 상태일 뿐이라 그쪽을 맞춘 것이다.
