# A-04. 시장 데이터 API

> **문서 버전** v2.0 · **관련 기능** [F-16](../../features/version2.0/F-16-시장데이터-파이프라인.md)

---

## 1. 공통 규약

### 1.1 모든 응답에 데이터 출처와 시각을 넣는다 ★

```jsonc
{
  "data": { },
  "source": "KIS",              // KIS | NAVER | YFINANCE | SIMULATION | UPBIT | PYKRX
  "as_of": "2026-08-11T14:23:11+09:00",
  "is_delayed": false,
  "is_simulated": false          // ★ 시뮬레이션 가격이면 true
}
```

**`is_simulated` 가 핵심이다.** v1.0 은 시뮬레이션 폴백 사실이 코드에만 있고
화면에는 안 보였다. API 가 이 값을 주면 화면이 배지를 달 수 있다.

### 1.2 캐시 미스 시

캐시가 만료됐으면 그 요청이 직접 갱신한다. 동시 갱신은 `FOR UPDATE SKIP LOCKED` 로
한 요청만 잡는다 (→ [F-16](../../features/version2.0/F-16-시장데이터-파이프라인.md) 2.4).

## 2. 주식

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/market/stocks?q=&market=&featured=` | 종목 목록·검색 |
| GET | `/api/market/stocks/<symbol>` | 종목 상세 |
| GET | `/api/market/quotes?symbols=005930,000660` | **배치 시세** |
| GET | `/api/market/orderbook/<symbol>` | 호가 10단계 |
| GET | `/api/market/chart/<symbol>?interval=1d&limit=200` | 봉 |
| GET | `/api/market/indices` | KOSPI · KOSDAQ |
| GET | `/api/market/movers` | 상승/하락 TOP |
| GET | `/api/market/rankings/market-cap` | 시총 랭킹 |

### 2.1 종목 검색 응답 — 대회 판정 포함 ★

```jsonc
{ "results": [
  { "symbol": "005930", "name": "삼성전자", "market": "KOSPI",
    "sector_code": "G45", "sector_name": "IT",
    "market_cap": 442000000000000,
    "avg_turnover_5d": 812000000000,
    "is_supervised": false, "alert_level": null,
    "listing_date": "1975-06-11",
    "contest_tradable": true,           // ★ 대회에서 매수 가능한가
    "contest_block_reasons": []          // 불가 사유 목록
  },
  { "symbol": "123456", "name": "소형주식", "market": "KOSDAQ",
    "contest_tradable": false,
    "contest_block_reasons": [
      { "code": "LOW_TURNOVER", "message": "5일 평균 거래대금 12.4억 (기준 30억)" },
      { "code": "LOW_MARKET_CAP", "message": "시가총액 820억 (기준 1,000억)" }
    ] }
] }
```

`contest_tradable=false` 인 종목을 **검색 결과에서 노란색으로 표시**한다.
(타임폴리오 방식 — → [ui/U-02](../../ui/version2.0/U-02-대회화면군.md))

`contest` 쿼리 파라미터를 주면 그 대회의 `rule_set` 기준으로 판정한다.

### 2.2 호가 응답

```jsonc
{
  "symbol": "005930",
  "asks": [ { "level": 1, "price": 74300, "qty": 1240 },
            { "level": 2, "price": 74400, "qty": 3100 } ],   // 매도 10단계
  "bids": [ { "level": 1, "price": 74200, "qty": 2050 } ],   // 매수 10단계
  "total_ask_qty": 28400, "total_bid_qty": 31200,
  "source": "KIS", "as_of": "...", "is_simulated": false
}
```

**연습 모드에서는 파생 호가 5단계**를 주고 `"source": "DERIVED"` 로 표시한다.

### 2.3 시세 조달 불가 (503)

```jsonc
{ "ok": false, "rule": "PRICE_UNAVAILABLE",
  "message": "시세를 조회할 수 없어 주문을 처리할 수 없습니다.",
  "detail": { "symbol": "123456", "last_known_price": 8200,
              "last_known_at": "2026-08-11T13:50:00+09:00" } }
```

> **v1.0 의 판단 승계** — KRX 검색으로 들어온 종목을 **가짜 가격으로 주문시키지 않기 위해
> 503 을 던진다.** 이 원칙을 유지하고, 대신 마지막으로 알던 값을 함께 알려준다.

## 3. 코인

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/market/crypto/markets` | KRW 마켓 목록 |
| GET | `/api/market/crypto/<code>` | 시세 |
| GET | `/api/market/crypto/<code>/domestic` | **국내 4사 비교** |
| GET | `/api/market/crypto/rankings` | **KRW 거래대금 기준** ★ |

### 3.1 국내 4사 비교 — 부분 실패 허용

```jsonc
{ "code": "KRW-BTC",
  "prices": { "upbit": 98500000, "bithumb": 98480000,
              "coinone": null, "korbit": 98510000 },   // ★ 실패는 null
  "as_of": "..." }
```

**개별 거래소 실패는 `null` 로 흘려보낸다.** v1.0 `_fetch_price_safely` 의 판단 승계 —
하나가 죽어도 화면이 죽지 않는다.

### 3.2 WebSocket 은 API 가 아니다

실시간 시세는 **브라우저가 업비트에 직접 연결**한다. 서버를 거치지 않는다.
nginx 중계 경로(`/upbit-websocket`)만 제공한다 (→ [F-16](../../features/version2.0/F-16-시장데이터-파이프라인.md) 6.2).

## 4. 대체자산


## 5. 뉴스 · 캘린더

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/market/news/krx` | KRX 보도자료 |
| GET | `/api/market/calendar?from=&to=` | 영업일 |

### 5.1 뉴스 — 실패를 숨기지 않는다 ★

```jsonc
{ "items": [ { "title": "...", "date": "2026-08-11", "views": 421,
               "pdf_url": "https://file.krx.co.kr/..." } ],
  "as_of": "2026-08-11T14:20:00+09:00",
  "is_stale": true,                                  // ★ 최신 수집 실패
  "stale_reason": "KRX 응답 지연 (마지막 성공 14:20)" }
```

> v1.0 은 실패 시 503 + 빈 배열이라 화면이 조용히 비었다.
> v2.0 은 **마지막 성공분을 주되 낡았음을 알린다.**
