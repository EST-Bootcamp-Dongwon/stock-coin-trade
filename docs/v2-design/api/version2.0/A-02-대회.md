## 2. 참가

| 메서드 | 경로 | 설명 |
|---|---|---|
| POST | `/api/contests/<id>/join` | `{ "nickname": "동원", "agree_rules": true }` |
| DELETE | `/api/contests/<id>/join` | 참가 포기 (`WITHDRAWN`) |

### 실패 응답

| `rule` | 상황 | 코드 |
|---|---|---|
| `ENTRY_CLOSED` | 신청 마감 | 400 |
| `CAPACITY_FULL` | 정원 초과 | 409 |
| `ALREADY_JOINED` | 이미 참가 | 409 |
| `NICKNAME_TAKEN` | 별칭 중복 | 400 |
| `REQUIREMENT_NOT_MET` | 참가 조건 미달 (학습 포인트 등) | 400 |

## 3. 내 현황

| 메서드 | 경로 |
|---|---|
| GET | `/api/contests/<id>/me` |
| GET | `/api/contests/<id>/guidelines` |

### 3.1 `/me` 응답

```jsonc
{
  "participation": { "nickname": "동원", "status": "APPROVED", "is_ranked": true },
  "account_id": 12,
  "nav": 1082.10, "nav_change": 3.20,
  "cumulative_return_pct": 8.21,
  "rank": 7, "rank_change": 1, "total_participants": 42,
  "invested_ratio_pct": 88.3, "position_count": 8,
  "cash": 12100000, "total_asset": 108200000,
  "warnings": [                                    // ★ 홈·대시보드에서 강조할 항목
    { "type": "TURNOVER", "level": "WARN",
      "message": "금주 회전율 2.4% (기준 5%)" }
  ]
}
```

### 3.2 `/guidelines` 응답 — 가이드라인 표 그대로

```jsonc
{
  "items": [
    { "key": "POSITION_LIMIT", "label": "종목별 한도",
      "standard": "15% (삼성전자 40%)", "current": "12.4%",
      "ok": true, "note": "주문 시 사전 차단" },
    { "key": "SECTOR_LIMIT", "label": "섹터별 한도",
      "standard": "max(시장섹터 2배, 10%)", "current": "하단 섹터 표 참조",
      "ok": true, "note": "가격 변동에 의한 일시적 초과 허용" },
    { "key": "SMALL_CAP", "label": "시총 1조 미만 비중",
      "standard": "30% 이하", "current": "0.0%", "ok": true },
    { "key": "TURNOVER", "label": "주간 회전율",
      "standard": "매주 5% 이상 유지", "current": "금주 2.4%",
      "ok": false, "note": "지속 위반 시 수상 제외 가능" },
    { "key": "TURNOVER_VIOLATION", "label": "주간회전율 위반",
      "standard": "위반 3번까지 허용",
      "current_confirmed": 1, "current_expected": 2, "ok": true }
  ],
  "help": {
    "turnover_formula": "(매수총액 + 매도총액) / 기간 평균 운용금액 × 0.5 × 100",

```

**`help` 를 API 가 함께 준다.** 툴팁 문구를 프론트에 하드코딩하지 않는다.

## 4. 랭킹

| 메서드 | 경로 |
|---|---|
| GET | `/api/contests/<id>/rankings?page=` |
| GET | `/api/contests/<id>/participants/<pid>` |
| GET | `/api/contests/<id>/top-picks?basis=today` |
| GET | `/api/contests/<id>/analysis` |
| GET | `/api/contests/<id>/result` |

### 4.1 랭킹 응답

```jsonc
{
  "as_of": "2026-08-11T14:20:00+09:00",
  "basis": "INTRADAY_SNAPSHOT",       // 장중은 10분 스냅샷 기준임을 명시
  "count": 42,
  "results": [
    { "rank": 1, "rank_change": 0, "nickname": "uzzan",
      "nav": 1340.26, "nav_change": -12.20,
      "invested_ratio_pct": 88.3, "position_count": 10,
      "is_ranked": true, "is_me": false }
  ],
  "my_rank": 7
}
```

### 4.2 참가자 상세 (포트폴리오 공개)

```jsonc
{
  "nickname": "uzzan",
  "intraday": [ { "at": "09:00", "return_pct": -0.2 } ],
  "nav_series": [ { "date": "2026-09-01", "nav": 1000, "kospi_nav": 1000, "kosdaq_nav": 1000 } ],
  "holdings": [ { "symbol": "A078600", "name": "대주전자재료",
                  "price": 93700, "change_pct": -4.9,
                  "qty": 1594, "weight_pct": 11.1, "value": 149360000,
                  "avg_price": 73292, "pnl_pct": 27.8, "pnl": 32530000 } ],
  "top_pnl": [ { "symbol": "A005930", "name": "삼성전자",
                 "pnl": 70967861, "pnl_share_pct": 20.8 } ],
  "recent_orders": [ /* 거래 이력 */ ]
}
```

> **현금·잔고 절대금액은 응답에 넣지 않는다.** 종목·비중·손익률만 공개한다.
> `Contest.portfolio_visibility` 가 `SELF_ONLY` 면 남의 것은 403.

### 4.3 Top Pick

```jsonc
{
  "basis": "today",                 // today | yesterday
  "participants": ["uzzan", "안온", "귤22"],
  "rows": [
    { "symbol": "A005930", "name": "삼성전자", "price": 241000, "change_pct": 4.8,
      "weights": { "uzzan": 4.0, "안온": 5.9, "귤22": 34.3 } }
  ]
}
```

### 4.4 결과 (종료 후)

```jsonc
{
  "confirmed_at": "2026-10-01T06:00:00+09:00",
  "results": [
    { "final_rank": 1, "nickname": "uzzan",
      "return_pct": 34.03, "return_score": 98.5,
      "management_score": 72.1, "final_score": 90.6, "grade": "A+" }
  ],
  "stats": { "avg_return_pct": 4.2, "max": 34.03, "min": -18.4 },
  "retrospective": {                            // ★ 회고 자료
    "most_held": [ { "symbol": "A005930", "holder_count": 31 } ],
    "most_profitable": [ { "symbol": "A247540", "total_pnl": 421000000 } ]
  }
}
```

## 5. 대회 유니버스 · 섹터

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/contests/<id>/universe?sector=&q=` | 거래 가능 종목 (대회 시작 시 고정된 섹터 포함) |
| GET | `/api/contests/<id>/sectors` | 시장 비중 vs 내 포트 비중 |

```jsonc
// /sectors
{ "sectors": [
  { "code": "G45", "name": "IT", "market_weight_pct": 24.1,
    "my_weight_pct": 47.2, "limit_pct": 48.2, "ok": true }
] }
```
