### 1.1 가입 요청·응답

```jsonc
// 요청

// 성공 201
{ "id": 1, "username": "dongwon", "display_name": "동원",
  "accounts": [
    { "id": 1, "mode": "PRACTICE_STOCK",  "cash": 100000000 },
    { "id": 2, "mode": "PRACTICE_CRYPTO", "cash": 100000000 },
    { "id": 3, "mode": "PRACTICE_ALT",    "cash": 100000000 }
  ] }
```

## 2. 계좌

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/accounts` | 내 계좌 전체 (연습 3 + 참가 중인 대회 계좌) |
| GET | `/api/accounts/<id>/snapshot` | **화면 하나를 그릴 수 있는 통합 응답** ★ |
| POST | `/api/accounts/<id>/reset` | 초기화 (**연습 계좌만**) |

### 2.1 `GET /api/accounts` 응답

```jsonc
{ "accounts": [
  { "id": 1, "mode": "PRACTICE_STOCK", "label": "주식 연습",
    "cash": 42350000, "total_asset": 103820000,
    "pnl_pct": 3.82, "position_count": 8, "is_frozen": false },
  { "id": 12, "mode": "CONTEST", "label": "RFM 1회 대회",
    "contest": { "id": 3, "name": "RFM 1회 대회", "status": "ONGOING",
                 "end_date": "2026-09-30", "d_day": 12 },
    "cash": 12100000, "total_asset": 108200000,
    "pnl_pct": 8.20, "position_count": 8, "rank": 7, "rank_change": 1,
    "is_frozen": false }
] }
```

### 2.2 `GET /api/accounts/<id>/snapshot` 응답

→ [F-09](../../features/version2.0/F-09-보유자산-포트폴리오.md) 3장 참조.

**API 3개를 호출하던 v1.0 구조를 1개로 합친다.** HTMX 프래그먼트 하나가
이 응답으로 요약·테이블·도넛을 전부 그린다.

### 2.3 `POST /api/accounts/<id>/reset`

```jsonc
// 요청
{ "keep_order_history": true }   // 이력은 남기고 포지션만 초기화

// 대회 계좌면 403
{ "ok": false, "rule": "CONTEST_ACCOUNT_IMMUTABLE",
  "message": "대회 계좌는 초기화할 수 없습니다." }
```

**해당 계좌만 초기화한다.** 다른 모드 계좌는 건드리지 않는다 (결함 D-5 해소).

## 4. API 키

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/account/api-keys` | 목록 (prefix · 계좌 · 최근 사용 · 최근 1시간 호출 수) |
| POST | `/api/account/api-keys` | 발급 — **`account_id` 필수** |
| DELETE | `/api/account/api-keys/<id>` | soft delete |

### 4.1 발급 응답 (평문 1회만)

```jsonc
{ "id": 5, "name": "내 봇",
  "key": "eduapi_live_XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX",  // ★ 이번 한 번만
  "key_prefix": "eduapi_live_XXXX",
  "account": { "id": 12, "label": "RFM 1회 대회" },
  "warning": "이 키는 다시 볼 수 없습니다. 안전한 곳에 보관하세요." }
```

목록 조회에서는 `key` 가 절대 나오지 않는다. DB 에는 `sha256(raw)` 만 저장한다.

## 5. 관심종목

| 메서드 | 경로 |
|---|---|
| GET | `/api/watchlist?asset_class=STOCK` |
| POST | `/api/watchlist` `{ "symbol": "005930", "asset_class": "STOCK" }` |
| DELETE | `/api/watchlist/<symbol>` |

**v1.0 은 `localStorage` 였다.** 서버 저장으로 승격해 기기 간 동기화된다.

첫 로그인 시 브라우저에 남은 `localStorage` 값이 있으면 **1회 병합**한다.
