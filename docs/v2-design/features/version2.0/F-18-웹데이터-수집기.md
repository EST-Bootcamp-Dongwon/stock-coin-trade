# F-18. 웹 데이터 수집기 (구 AI Sheet)

> **문서 버전** v2.0 · **분류** 기능=살림 · 구현=포팅
> **v1.0 대응** 1-18 AI Sheet (`ai_sheet.py` 126줄)
> **확정** **이름 바꾸고 존치**

---

## 1. 개명 ★ (결함 D-11 해소)

> v1.0 의 "AI Sheet" 는 **AI/LLM 을 전혀 쓰지 않는다.** 규칙 기반 HTML 표 추출기다.

이름과 실제가 다르면 사용자가 기대를 잘못 갖고, 나중에 "AI 가 어디 있냐"는 질문이 나온다.

| | |
|---|---|
| v1.0 | AI Sheet · `/ai-sheet.html` |
| **v2.0** | **웹 데이터 수집기** · `/tools/web-scraper/` |
| 위치 | GNB "도구" 메뉴 |

---

## 2. 왜 살리는가

대회 도메인과의 관련성은 가장 약하다. 그럼에도 살리는 이유:

1. **SSRF 방어 로직의 가치가 크다.** 직접 다시 짜면 실수하기 쉬운 영역이다
2. 투자 데이터를 다루는 학습 서비스에서 "웹에서 표를 긁어 분석한다"는 흐름은 자연스럽다
3. 강사님 기능을 누락시키지 않는다

---

## 3. SSRF 방어 (v1.0 그대로 포팅) ★

**이 기능의 핵심이다. 한 줄도 빼놓지 않고 옮긴다.**

| 방어 | 내용 |
|---|---|
| scheme 제한 | `http` / `https` 만 |
| port 제한 | 80 / 443 만 |
| 자격증명 거부 | URL 에 user/password 가 있으면 거부 |
| **DNS 검증** | `getaddrinfo` 로 **모든 A/AAAA 레코드가 global 주소인지** 검증 (사설망·루프백 차단) |
| **리디렉션 재검증** | **리디렉션 후 최종 URL 도 다시 검증** ← 흔히 빠뜨리는 지점 |
| Content-Type | `html` 없으면 415 |
| 크기 제한 | 2MB 초과면 413 |
| 파싱 상한 | 최대 100행 × 20열 · 셀당 500자 · 문단당 1000자 |

### 3.1 Django 에서 주의할 점

> **Django 관점** — FastAPI 에서 `requests` 로 직접 호출하며 방어를 걸었다면,
> Django 에서도 동일하게 **HTTP 클라이언트 레벨에서** 막아야 한다.
> `requests` 의 `allow_redirects=True` 를 그대로 쓰면 리디렉션 검증을 못 한다.
> **`allow_redirects=False` 로 두고 직접 따라가며 매 홉을 검증**하는 v1.0 방식을 유지한다.

---

## 4. 파서 (v1.0 승계)

- 표준 `html.parser` 자체 구현 (외부 라이브러리 없음)
- **가장 셀이 많은 표**를 선택
- 표가 없으면 20자 이상 문단들을 "순번·본문" 2열로 대신 채움

---

## 5. 프론트 (v1.0 승계 + 확장)

| 기능 | v1.0 | v2.0 |
|---|---|---|
| 헤더·셀 인라인 편집 | ✅ | ✅ |
| 행 추가 | ✅ | ✅ + 행 삭제 · 열 삭제 |
| **CSV 다운로드** (BOM 포함 → Excel 한글 정상) | ✅ | ✅ |
| **시트 저장** | ✕ (새로고침하면 사라짐) | **신규** — `SavedSheet` 모델 |

### 5.1 시트 저장

```
SavedSheet(member, title, source_url, data(JSON), created_at, updated_at)
```

수집한 표를 저장해두고 나중에 다시 열 수 있다.
v1.0 은 새로고침하면 사라져서 실용성이 떨어졌다.

---

## 6. 인증

v1.0 은 `/api/ai-sheet/crawl` 이 **인증 없이 열려 있었다**(결함 D-6 계열).
외부 URL 을 우리 서버가 대신 호출해 주는 기능이라 **오남용 위험이 있다.**

| 항목 | v2.0 |
|---|---|
| 인증 | **로그인 필수** |
| 사용량 제한 | 회원당 **1일 50회** |
| 호출 로그 | `WebFetchLog(member, url, status, size, created_at)` — 오남용 추적 |

---

## 7. LLM 도입 여부

**1차에는 도입하지 않는다.** 개명으로 이름-실제 불일치는 해소되었고,
LLM 추출은 비용이 붙고 정확도 검증이 필요하다.

v2.1 에서 "표가 없는 페이지도 구조화" 옵션으로 검토한다.
