## 2. v2.0 의 홈 — 대회가 주역

**v2.0 의 홈은 대회 중심이다.** Top 10 위젯은 유지하되 주역이 아니게 된다.

## 3. 위젯 상세

### 3.1 내 대회 현황 ★

가장 중요한 위젯이다. **참가자가 매일 확인해야 하는 정보**를 한 곳에 모은다.

| 항목 | 비고 |
|---|---|
| 대회명 · D-day | 남은 기간 |
| 순위 · 등락 | `7 (3↑)` |
| 기준가(NAV) · 수익률 | |
| 편입비 · 보유 종목 수 | |
| **회전율 경고** | 기준 미달 시 노란색 강조 ← 타임폴리오도 홈에 표시한다 |
| **한도 초과 경고** | 편입한도 초과 상태면 빨간색 |
| 빠른 이동 | 주문 · 랭킹 · 포트폴리오 |

여러 대회에 동시 참가 중이면 **탭 또는 카드 나열**로 보여준다.

### 3.2 시장 현황 (v1.0 승계 + 수정)

| 위젯 | v1.0 | v2.0 |
|---|---|---|
| 코인 Top 10 | 업비트 WebSocket 실시간 | **유지** |
| 주식 Top 10 | 30초 폴링 · **등락률 절대값 정렬** | **상승 Top 5 / 하락 Top 5 로 분리** ★ |
| 지수 | 없음 | **KOSPI · KOSDAQ 추가** |

> **v1.0 의 절대값 정렬은 의도가 불분명하다.** 상승·하락이 섞여 나와
> "지금 뭐가 오르나"를 알 수 없다. 상승/하락을 나눠서 보여준다.

### 3.3 학습 진행률

`LearningProgress` 기반 (→ [F-17](F-17-학습콘텐츠.md) 4장).
"이어서 학습하기"로 마지막 레슨에 바로 진입한다.

## 4. 성능 원칙

홈은 **가장 많이 열리는 화면**이다.

| 원칙 | |
|---|---|
| 외부 API 직접 호출 금지 | 전부 캐시 테이블에서 읽는다 (→ [F-16](F-16-시장데이터-파이프라인.md)) |
| 내 대회 현황 | `ContestRanking` · `DailySnapshot` 조회. 계산하지 않는다 |
| 코인 실시간 | 브라우저 ↔ 업비트 WebSocket **직접** (서버 부하 0) |
| HTMX 부분 갱신 | 위젯별로 독립 갱신. 하나가 느려도 나머지는 뜬다 |
