## 1. 성격

v1.0 의 주식 거래 화면은 **전체 중 최대 규모**(HTML 492줄 · JS 858줄)이고
강사님이 벤치마킹을 반영해 기능을 계속 얹은 화면이다.
**이 화면의 기능은 하나도 빼지 않고 연습 모드로 옮긴다.**

대회 모드와의 차이:

| | 연습 | 대회 |
|---|---|---|
| 규칙 | 없음 | 편입한도·섹터·회전율 |
| 시세 | yfinance → 네이버 → 시뮬레이션(14종) | KIS → 네이버 (시뮬레이션 금지) |
| 호가 | 현재가에서 파생 생성 (5단계) | **KIS 실호가 10단계** |
| 체결 | 현재가 전량 즉시 | 호가 잔량 소진 방식 |
| 거래 시간 | 상시 (장외는 최종가) | 영업일 09:00~15:30 |
| 수수료 | 0.015% + 매도세 0.18% | 10bp + 20bp |
| 계좌 초기화 | 가능 | 불가 |

### 2.1 호가창 정직성 ★

v1.0 은 호가 5단계를 **현재가에서 파생 생성**했다. 실제 호가가 아니다.
코드에만 있고 화면에는 표시가 없었다.

**v2.0 은 화면에 명시한다.** — "이 호가는 현재가 기반 참고 표시이며 실제 시장 호가가
아닙니다. 실호가는 대회 모드에서 제공됩니다."

이게 대회 모드로 넘어갈 동기도 된다.

### 2.2 시뮬레이션 가격 배지 ★

v1.0 의 3단 폴백에서 3순위(시뮬레이션)로 떨어진 종목은 **화면에 배지를 단다.**
v1.0 은 이 사실이 사용자에게 보이지 않았다.

## 5. 계좌 초기화

```
POST /practice/stock/reset
  → 이 계좌의 Position 전부 삭제
  → 이 계좌의 Order 전부 삭제 (또는 보존 옵션)
  → cash = 1억
```

**다른 모드 계좌는 건드리지 않는다.** v1.0 결함 D-5(주식 초기화가 코인을 안 지워
총자산이 1억을 초과하던 문제)가 구조적으로 사라진다 — 계좌가 분리되어 있으므로.

> 주문 이력을 지울지 남길지는 화면에서 선택하게 한다.
> "이력은 남기고 포지션만 초기화" 가 학습 회고에 유리하다.
