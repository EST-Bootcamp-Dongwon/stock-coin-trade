### 2.2 콘텐츠 ↔ 로직 분리 ★

> v1.0 은 `analysis.js` **650줄(단일 JS 최대)**에 콘텐츠와 로직이 뒤엉켜 있다.
> 그대로 옮기면 유지보수가 안 된다.

v2.0:

| 대상 | 위치 |
|---|---|
| 레슨 텍스트 · 예제 코드 · 데이터 표 | **DB (`Lesson` 모델)** 또는 마크다운 파일 |
| 렌더링 · 인터랙션 | Django 템플릿 + Alpine.js |

## 4. 진행률 서버 저장 ★ (확정 사항)

### 4.1 v1.0 의 문제

`localStorage` 키 `edumgt-investment-academy-progress-v1` 에만 저장.

- **기기를 바꾸면 사라진다**
- 브라우저 데이터를 지우면 사라진다
- **대회 참가 조건으로 쓸 수 없다**

### 4.2 v2.0

```
LearningProgress(member, lesson_key, progress_points, completed_at, updated_at)
   UNIQUE(member, lesson_key)
```

| 항목 | 처리 |
|---|---|
| 저장 시점 | 입력칸 변경·실행 버튼 클릭 시 **디바운스 후 서버 저장** (HTMX `hx-trigger="change delay:1s"`) |
| 전역 목표 | 100포인트 (v1.0 승계) |
| 학습 홈 | 그룹별 진행률 바 · 총 진행률 · 최근 학습 레슨 |
| **기존 데이터 이관** | 첫 로그인 시 `localStorage` 값이 있으면 서버로 1회 병합 |

### 4.3 대회와의 연결 (선택 기능)

```
Contest.entry_requirement = { "min_learning_points": 30 }
```

**"학습 30포인트 이상 달성 후 참가 가능"** 같은 게이트를 걸 수 있다.

- 1차에는 **필드만 만들고 기본값은 제한 없음**으로 둔다
- 동아리 운영 방침에 따라 켜고 끌 수 있게
