# F-12. Pine 전략거래

> **문서 버전** v2.0 · **분류** 기능=개선 · 구현=수정포팅
> **v1.0 대응** 1-15 Pine 전략거래 (`pine.js` 127줄 · `stocks.py::pine_order`) · 1-16 Pine 안내
> **확정** 자동 실행은 **하지 않는다.** 1차는 수동 실행만

---

## 1. 성격

**Pine Script 를 브라우저에서 정규식으로 파싱**해 매매 신호를 만들고,
그 신호로 모의 주문을 낸다. 진짜 인터프리터가 아니다.

| 지원 범위 (v1.0) | |
|---|---|
| 지표 | `ta.sma` · `ta.ema` · `ta.rsi` (전부 JS 재구현) |
| 조건 | `ta.crossover` · `ta.crossunder` |
| 입력 | `input.float(...)` (`/100` 표기 감지) |
| 진입/청산 | `strategy.entry(..., strategy.long)` · `strategy.close` 앞 2줄 안에 참인 조건 변수 |

---

## 2. v1.0 의 좋은 판단 — 그대로 승계 ★

> **주문은 서버 권위.** 파싱·신호 생성은 브라우저에서 하되 체결은 서버가 하고
> `source="PINE"` 라벨을 붙여 **수동 웹 주문과 섞이지 않게** 한다.
> (v1.0 코드 주석에 이 의도가 명시되어 있다)

v2.0 도 동일하다. 신호는 클라이언트, 체결은 서버, 라벨은 `PINE`.

---

## 3. v2.0 개선 항목

### 3.1 GNB 노출 (결함 D-2 해소) ★

v1.0 은 `/trade/pine.html` 과 `/trade/pine-guide.html` 이 **`common.js` 의 `navGroups` 에 없어**
학습 페이지 링크로만 들어갈 수 있었다. **사실상 발견되지 않는 기능**이었다.

v2.0 은 GNB 에 정식 노출한다 (→ [ui/U-01-공통레이아웃-GNB](../../ui/version2.0/U-01-공통레이아웃-GNB.md)).

### 3.2 지원 문법 범위 명시 ★

정규식 파서는 지원 문법이 극히 제한적이라 **조금만 벗어난 스크립트도 조용히
"신호 없음"이 된다.** 사용자는 왜 안 되는지 모른다.

v2.0 처리:

| 항목 | 처리 |
|---|---|
| **지원 문법 표를 화면에 상시 표시** | 지표 3종 · 조건 2종 · 입력 1종 |
| **파싱 결과를 보여준다** | "인식된 지표: SMA(20), SMA(60) / 인식된 조건: crossover" |
| **인식 못한 줄을 표시** | "3행 `ta.macd(...)` 는 지원하지 않습니다" ← **핵심 개선** |
| 파서 강화 | v2.1. 1차는 "무엇을 못 읽었는지 알려주기"까지 |

### 3.3 내장 예제 (v1.0 승계)

3종 유지: 이동평균 교차 / 3% 익절·1.5% 손절 / RSI 반전

### 3.4 익절·손절 시각화 (v1.0 승계)

`strategy.exit` + 보유 포지션이 있으면 평단 기준 익절가·손절가를 계산하고,
최신 봉의 고가/저가가 그 선에 닿았는지로 신호를 뒤집는다. 그대로 유지.

## 4. 자동 실행을 하지 않는 이유 (확정)

| | |
|---|---|
| **확정** | 1차는 **수동 실행만**. 사용자가 버튼을 눌러야 주문이 나간다 |
| 근거 | 서버가 참가자 코드를 대신 실행하는 구조는 **안전성·부하 설계가 별도로 필요**하다. 무한 루프·과도한 주문·경쟁 조건을 다 막아야 한다 |
| 대안 경로 | 자동매매가 필요하면 **[Open API](F-13-OpenAPI.md)(자기 봇)** 로 유도한다. 이미 있는 경로이고 rate limit 으로 통제된다 |
| 대회 규칙 | 대회 안내문에 "Pine 전략은 수동 실행만 가능하며, 자동매매는 Open API 를 이용하십시오"를 명시 |

## 5. 백테스트 — v2.1

v1.0 은 **"최신 봉의 신호"만 판정**한다. 과거 구간 성과를 볼 수 없다.

백테스트를 넣으려면:
- 과거 봉 데이터 저장이 선행되어야 한다 (`ChartCache` 는 TTL 캐시라 부적합)
- 체결 가정(다음 봉 시가 체결 등)을 정의해야 한다
- 수수료·슬리피지를 반영해야 한다

**v2.1 로 미룬다.** 다만 [F-17 학습 콘텐츠](F-17-학습콘텐츠.md)의
"백테스트 성과 지표" 인터랙티브 레슨은 그대로 살아 있어, 개념 학습은 가능하다.
