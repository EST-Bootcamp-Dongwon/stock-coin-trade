# F-14. AI 분석 (Claude)

> **문서 버전** v2.0 · **분류** 기능=개선 · 구현=수정포팅
> **v1.0 대응** 1-8 AI 분석 (`ai.py` 78줄 · `common.js::runAiAnalysis`)

## 1. v1.0 동작

전 화면 공통 **오른쪽 오프캔버스 패널** → "AI 분석" 탭.

```
① 현재 화면 DOM 에서 시세를 긁어 컨텍스트 구성 (collectMarketContext)
② Qdrant 시맨틱 검색
③ 검색 근거를 유사도%와 함께 접이식 UI 로 표시
④ 시세 + 근거를 합쳐 Claude 에 전달
⑤ 스트리밍 응답을 마크다운 렌더링
```

- 모델 `claude-haiku-4-5-20251001`, `max_tokens: 1024`, stream
- `ANTHROPIC_API_KEY` 미설정 시 안내 메시지를 **스트리밍으로 반환**해 화면이 깨지지 않음
- 시스템 프롬프트에 "투자 교육 목적이며 실제 투자 결정은 본인 판단" 고지 포함

## 2. v2.0 변경점

### 2.1 DOM 스크래핑 → 서버 사이드 컨텍스트 조립 ★

**v1.0 의 가장 취약한 지점이다.** 화면 구조가 바뀌면 컨텍스트가 조용히 비어버리고,
AI 는 아무 데이터 없이 그럴듯한 답을 만든다. 사용자는 이를 알아채기 어렵다.

v2.0 은 서버가 직접 조립한다.

```
POST /api/ai/analyze  { "scope": "MY_PORTFOLIO", "account_id": 1 }
   → 서버가 Account · Position · QuoteCache · DailySnapshot 을 직접 조회
   → 컨텍스트 조립 (신뢰 가능)
   → pgvector 검색 (→ F-15)
   → Claude 스트리밍
```

### 2.2 분석 범위 확장

| 범위 | v1.0 | v2.0 |
|---|---|---|
| 코인 시장 | ✅ | ✅ |
| 주식 시장 | ✅ | ✅ |
| 전체 시장 개요 | ✅ | ✅ |
| **내 포트폴리오** | — | **신규** — 실제 보유 종목·비중·손익 기준 분석 |
| **대회 맥락** | — | **신규** — 내 순위·한도 여유·회전율 현황을 함께 넣음 |

### 2.3 인증 필수 (결함 D-6 해소) ★

> v1.0 은 `/api/ai/analyze` 가 **인증 없이 열려 있었다.** Claude API 비용이 발생하는
> 엔드포인트가 누구에게나 열려 있던 것이다.

v2.0:

| 항목 | 처리 |
|---|---|
| 인증 | **로그인 필수** |
| 사용량 제한 | **회원당 1일 N회** (기본 20회). `AiUsageLog` 로 집계 |
| 대회 기간 제한 | 대회 참가자는 별도 쿼터 부여 가능 |
| 초과 시 | 429 + "오늘의 분석 횟수를 모두 사용했습니다 (20/20)" |

### 2.4 모델 선택

| 용도 | 모델 |
|---|---|
| 기본 (시장 요약·간단 분석) | **Claude Haiku 4.5** — v1.0 승계. 빠르고 저렴 |
| 심층 (포트폴리오 진단·대회 전략) | **Claude Sonnet 5** — 선택적. 쿼터를 더 크게 차감 |

**모델명은 설정값으로 뺀다.** 코드에 하드코딩하지 않는다.

## 4. 고지 강화 ★

모의투자 교육 서비스이므로 다음을 명확히 한다.

- 시스템 프롬프트에 고지 유지
- **응답 하단에 고정 문구 표시** (스트리밍 종료 후 서버가 덧붙임)
- 프롬프트에 **"특정 종목의 매수·매도를 권유하지 말 것"** 지시 추가
- 대회 참가자에게는 **"타 참가자의 포트폴리오를 근거로 한 추천을 하지 말 것"** 추가
  (Top Pick 화면 때문에 남의 포트폴리오가 컨텍스트에 들어갈 수 있다)

## 5. 서버리스에서의 SSE

**Vercel 서버리스 함수는 실행 시간 제한이 있다.** 스트리밍이 길어지면 잘린다.

| 처리 | |
|---|---|
| `max_tokens` 제한 유지 (1024) | 응답 길이를 통제 |
| 타임아웃 근접 시 정상 종료 | 잘린 채 끊기지 않고 "응답이 길어 여기서 마칩니다" 로 마무리 |
| 실패 시 재시도 안내 | 사용자 쿼터를 차감하지 않는다 |
