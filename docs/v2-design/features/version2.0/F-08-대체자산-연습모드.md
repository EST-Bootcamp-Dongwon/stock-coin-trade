> **v1.0 대응** 1-14 대체투자 (`alternatives.py` 181줄 · `alternatives.js`)

## 1. 성격

외부 의존이 전혀 없어 **v1.0 기능 중 가장 안전하게 옮길 수 있다.**
카탈로그·가격 생성 수식·증거금 계산을 그대로 포팅한다.

---

## 2. 왜 대회에서 뺐는가 ★

> 가격이 `sin(오늘의 서수 × 0.71 + 심볼문자합)` 기반의 **결정론적 수식**이다.

이 수식은 소스 코드에 있고, 저장소는 Public 이다.
**참가자가 내일 가격을 미리 계산할 수 있다.** 대회에 넣으면 순위가 무의미해진다.

연습 모드에서는 문제가 없다. 오히려 장점이 있다.

- 외부 시세 라이선스에 의존하지 않는다
- 같은 날에는 주문가와 평가가가 항상 일치해 학습용으로 명확하다
- 선물·옵션·증거금 개념을 안전하게 익힐 수 있다

> v2.2 에서 대체자산 대회를 열려면 **시드를 서버 비공개 난수로 교체**해야 한다.
> 그때는 "같은 날 주문가 = 평가가" 성질이 깨지므로 별도 설계가 필요하다.

## 4. 승계하는 동작

| 기능 | 처리 |
|---|---|
| 영업일 단위 가격 생성 (옵션·파생 진폭 1.8% / 나머지 0.9%) | 유지 |
| 일봉 차트 (마지막 종가가 현재 주문 기준가와 일치하도록 스케일 보정) | 유지 |
| **증거금 개념** — 선물은 명목금액이 아니라 납부 증거금 기준으로 손익 표시 | 유지 |
| `FUT-K200` 실제 계약 규모 안내 (`pointScale 1000` · `actualMultiplier 250,000`) | 유지 |
| **부동산 Leaflet 지도** (강남·판교·해운대 마커) | 유지 |
| 교육용 고지 문구 | 유지 |

### 4.1 `ensure_tables()` 는 폐기한다

v1.0 은 앱 기동 시 `CREATE TABLE IF NOT EXISTS` 를 실행해 "재배포만으로 새 기능이
동작"하게 했다. 영리한 장치였지만 **Django 마이그레이션과 충돌**한다.

v2.0 은 정규 마이그레이션(`makemigrations` → `migrate`)을 쓴다.

## 5. v2.1 이후 개선 항목 (v1.0 미비점)

| 항목 | 현재 상태 |
|---|---|
| 선물·옵션 **만기·정산** | 없음 — 만기 없는 영구 포지션 |
| 증거금 부족 시 **마진콜·강제청산** | 없음 |
| 공매도·숏 | 없음 (인버스로 우회) — [확정: 미도입](02-확정사항-8건.md) |

**1차는 v1.0 상태 그대로 간다.** 만기·마진콜을 넣으면 대체자산만으로
범위가 크게 늘고, 연습 모드라 우선순위가 낮다.

다만 **화면에 "만기·마진콜이 없는 단순화 모델"임을 명시**한다.
실제 파생상품과 다르다는 점을 학습자가 알아야 한다.
