## 2. 학습 홈 (`/learn/`) ★ 신규

v1.0 은 학습 화면이 세 군데로 흩어져 있고 진입점이 없었다. **통합 허브를 만든다.**

```
┌─ 내 학습 진행률 ─────────────────────────────┐
│  ████████░░░░░░░░  32 / 100 포인트            │
│  [이어서 학습하기 → 기술적 분석 · 추세 분석]        │
└────────────────────────────────────────────┘
┌─ 투자분석 6그룹 14레슨 ───────────────────────┐
│ 매크로 분석    ██░░  2/2                      │
│ 산업 분석      ░░░░  0/2                      │
│ 기본적 분석    ███░  2/3                      │
│ 기술적 분석    █░░░  1/4                      │
│ 일자별 학습    ░░░░  0/2                      │
│ 분석 도구      ░░░░  0/1                      │
└────────────────────────────────────────────┘
┌─ 가이드 ────────────────────────────────────┐
│ [KB증권 모의투자]  [KIS Developers]            │
│ [TradingView Pine] [Pine 기초]                │
│  ℹ️ 2026-08-11 기준                            │
└────────────────────────────────────────────┘
```

**진행률은 서버 저장**이라 기기를 바꿔도 이어진다 (→ [F-17](../../features/version2.0/F-17-학습콘텐츠.md) 4장).

## 3. 투자분석 레슨 (`/learn/analysis/<lesson>/`)

### 3.1 레슨 화면 구성 (v1.0 승계)

```
┌─ 좌: 레슨 목차 ──┬─ 우: 레슨 본문 ───────────────┐
│ 매크로 분석 ✅    │  [레슨 제목]                     │
│  · 경제지표 ✅    │                                │
│  · 거시경제 ✅    │  이론 3줄                        │
│ 산업 분석        │  💡 팁                           │
│  · 산업 경쟁력   │                                │
│  · 산업 분석실습 │  ```python                      │
│ 기본적 분석      │  예제 코드                        │
│  ...            │  ```                            │
│                 │                                │
│                 │  예시 데이터 표                    │
│                 │                                │
│                 │  [입력칸] [실행]                  │
│                 │  ┌ 결과 카드 ─────────────┐      │
│                 │  │ 수치 + 막대그래프 + 해설  │      │
│                 │  └───────────────────────┘      │
│                 │  SVG 일러스트 (기술적 분석 레슨)     │
│                 │  [◀ 이전]  [다음 ▶]              │
└─────────────────┴────────────────────────────────┘
```

### 3.2 진행률 저장

```html
<input hx-post="{% url 'learn:progress' lesson.key %}"
       hx-trigger="change delay:1s"
       hx-swap="none">
```

디바운스 1초. 타이핑할 때마다 서버를 때리지 않는다.

### 3.3 퀀트 모델링(5일차) 인터랙티브 3종

계산은 **클라이언트(Alpine)** 에서. 즉시 반응해야 학습이 된다.

| # | 인터랙션 |
|---|---|
| 1 | 백테스트 성과 지표 — 전략 × 거래비용 슬라이더 → CAGR·MDD·Sharpe·승률 |
| 2 | 시장 계절성 — 월별/요일 효과 토글 |
| 3 | Pine Script 기초 — 템플릿 편집 + 구조 점검 → [Pine 전략 화면](U-03-거래화면군.md) 링크 |

## 5. 물타기 계산기 (`/tools/avg-down/`)

**보유 없이도 숫자만 넣어 계산**하는 독립 페이지. v1.0 방식.

```
┌─ 입력 ──────────────────────┐
│ 보유 수량   [___]            │
│ 보유 평균가 [___]            │
│ 추가 매수가 [___]            │
│ ○ 수량 입력  ● 금액 입력       │
│ 추가 매수 [___]              │
│ ─── 또는 ───                │
│ 목표 평균가 [___] → 역산       │
└─────────────────────────────┘
┌─ 결과 ──────────────────────┐
│ 추가 매수 금액 / 수량           │
│ 총 보유 수량 / 총 매수 금액      │
│ 신규 평균 매수가 · 변동률        │
│ 본전까지 필요 상승률 ★           │
└─────────────────────────────┘
ℹ️ 보유 종목에서 바로 계산하려면 거래 화면의 [물타기] 버튼을 이용하세요.
```

**포지션 연동 모달과 진입점이 다를 뿐 계산 로직은 같다.**
