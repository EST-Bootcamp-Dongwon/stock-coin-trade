## 4. 대회 대시보드 (`/contests/<id>/me/`) ★

**참가자가 매일 여는 화면.** 구성은 [00-화면목록-라우팅](00-화면목록-라우팅.md) 3장 참조.

### 4.1 가이드라인 표

타임폴리오와 동일한 4열 구성.

| 가이드라인 | 기준 | 현재 | 비고 |
|---|---|---|---|
| 종목별 한도 | 15% (삼전 40%) | 12.4% | 주문 시 사전 차단 |
| 섹터별 한도 | max(시장섹터 2배, 10%) | 하단 섹터 표 참조 | 가격 변동에 의한 일시적 초과 허용 |
| 시총 1조 미만 비중 | 30% 이하 | 0.0% | |
| 주간 회전율 | 매주 5% 이상 유지 | **금주 2.4%** | 지속 위반 시 수상 제외 가능 |
| 주간회전율 위반 | 위반 3번까지 허용 | 금주 제외(확정) 누적 1번 | |
| | 4번 이상 순위/시상 제외 | 금주 포함(예상) 누적 2번 | |

- **위반·기준 미달은 빨간색**
- 각 항목에 `?` 툴팁 — 산식과 판정 방식 설명
- **"월요일 아침에는 예상 위반이 1회로 보이는 게 정상"** 안내를 회전율 툴팁에 포함
  (→ [F-04](../../features/version2.0/F-04-대회-규칙엔진.md) 5.2)

### 4.2 주문 타겟 표

타임폴리오의 독특한 개념이다. **목표 비중을 정해두고 그에 맞춰 주문**한다.

| 종목 | | 비중% | | | | (만원) | 추가 |
|---|---|---|---|---|---|---|---|
| 코드 | 종목명 | 전일 | 주문 | 미체결 | 타겟 | 금액 | + |
| A005930 | 삼성전자 | 32.6 | | 0 | 34.3 | 1,437 | + |
| A000660 | SK하이닉스 | 10.0 | | 0 | 10.2 | 116 | + |
| A009150 | 삼성전기 | 14.9 | **-5.0** | 0 | 10.0 | -58 | + |

- `+` 클릭 → 해당 종목의 주문 내역 펼침 (타임폴리오 동작)
- **미체결이 있으면 노란색**으로 비중·건수 표시
- 하단 Totals 행

### 4.3 하단 탭

| 탭 | 내용 |
|---|---|
| 가이드라인 위반 | 위반 이력 목록 |
| **도움말** | 규칙 설명 (타임폴리오처럼 화면 안에 상시 제공) |
| 섹터 비중 | 시장 vs 포트폴리오 섹터 비교표 |
| 일별 체결합 | 날짜별 매수·매도 합계 |
| 주문 내역 | 이 대회의 주문 전체 |
| 진입/청산 내역 | 종목별 진입·청산 쌍과 실현손익 |
| 섹터 유니버스 | 이 대회에서 거래 가능한 종목 목록 (섹터별) |

## 5. 신규 주문 모달 ★

[00-화면목록-라우팅](00-화면목록-라우팅.md) 3.1 참조. 핵심 차별점은 **정보 밀도**다.

| 영역 | 내용 |
|---|---|
| 종목 | 검색 선택 · **현재가 · 등락률 실시간** |
| **내 상태** | 보유 수량 · 평단 · 손익률 · **현재 비중 / 한도** ← v2.0 신규 |
| **한도 여유** | "최대 추가 매수 15,230,000원" ← v2.0 신규 |
| 매수/매도 | 토글 |
| 주문 비중(%) | 입력 + **슬라이더** |
| 가격 유형 | 상대호가 / 자기호가 / 지정가 / STOP |
| 호가 단계 | 1~10 (상대·자기호가 시) |
| **호가창** | 실호가 10단계 표시 ← v2.0 신규 (타임폴리오에 없음) |
| 실행 방식 | 즉시 실행 / ~~시간 분할~~ (v2.1 · 비활성 표시) |
| **비용 미리보기** | 체결금액 · 수수료 · 매도세 · 정산금액 ← v2.0 신규 |
| 제출 | |

### 5.1 실패 시 표시

```
❌ 편입 한도 초과
   삼성전자 비중이 42.1% 가 되어 한도 40% 를 초과합니다.
   현재 38.5% → 주문 후 42.1% (한도 40.0%)
   ▸ 최대 추가 매수 가능액: 15,230,000원   [이 금액으로 채우기]
```

**"이 금액으로 채우기" 버튼**을 제공한다. 참가자가 숫자를 바꿔가며 재시도하지 않게 한다.

## 6. 랭킹 (`/contests/<id>/ranking/`)

### 6.1 탭

| 탭 | 내용 |
|---|---|
| **수익률 순위** | 기본 |
| **Top Pick** | 종목 × 참가자 매트릭스 |
| 참여 포트폴리오 분석 | 산점도 |

### 6.2 안내문 (타임폴리오 방식 승계)

```
※ 전 참가자의 보유 종목과 수익 종목이 공개됩니다.        ← v2.0: "상위 10개" → "전 참가자"
※ [순위] : 수익률 순위. 최종 운영 능력 평가와는 무관
※ [액티브] : 주별 회전율 5% 이상 유지
```

### 6.3 표

| 순위 | | 별칭 | 기준가 | | 포트폴리오 | | |
|---|---|---|---|---|---|---|---|
| 현재 | 등락 | | 현재 | 등락 | 편입비 | 종목수 | 상세 |
| 1 | - | uzzan | 1,340.26 | -12.20 | 88.3 | 10 | [열기] |
| 2 | - | 드래곤플라이 | 1,252.72 | -6.75 | 0.0 | 2 | [열기] |
| 7 | 1↑ | **나** | 1,082.10 | +3.20 | 88.3 | 8 | [열기] |

- **내 행 하이라이트** + "내 순위로" 스크롤 버튼
- 실격자는 순위 칸 `-` + 회색 처리
- 검색·필터 (별칭 검색)

## 7. 참가자 상세 모달 ★

**v2.0 의 차별점.** 벤치마크는 50등 이후를 못 본다. 우리는 전부 공개한다.

```
┌─ uzzan ────────────────────────────────── ✕ ┐
│ [Intraday Return (%)]     [Daily NAV]        │
│  Portfolio·KOSPI·KOSDAQ    Portfolio·KOSPI·KOSDAQ │
│                                              │
│ 보유 종목 (전체)                                │
│  코드·종목명·현재가·당일%·잔고·비중%·평가액       │
│  ·평단가·손익률%·손익                          │
│                                              │
│ 수익 종목 (전체)                                │
│  종목코드·종목명·손익·수익/총수익(%)             │
│                                              │
│ 거래 이력                          ← v2.0 신규  │
│  시각·종목·매수/매도·수량·체결가                 │
└──────────────────────────────────────────────┘
```

**현금·잔고 절대금액은 가린다.** 종목·비중·손익률만 공개한다.

## 8. Top Pick (`/contests/<id>/top-picks/`)

```
※ 수익률 상위 참가자들의 주요 종목 30개
[전일 종목] [당일 종목]        ← 토글

         | uzzan | 안온 | 귤22 | 푸지후지 | ...
삼성전자   |  4.0  | 5.9 | 34.3|  38.8   |
SK하이닉스 |  3.0  | 7.0 | 22.7|  28.2   |
NAVER     |       |     |  5.9|         |
```

- 셀 값 = 비중 %. **값이 클수록 진한 배경**
- 행(종목) 클릭 → 그 종목의 시세·차트 팝오버
- 열(참가자) 클릭 → 참가자 상세 모달
- **가로 스크롤** + 첫 열(종목) 고정

## 9. 포트폴리오 분석 (`/contests/<id>/analysis/`)

```
분석 유형: [운용 능력 평가 ▾]
 y축: 수익 점수    x축: 관리 점수

        수익
         │    ● uzzan
         │  ●        ● 안온
         │      ● 나
         │ ●  ●
         └──────────── 관리
```

- 점 크기 = 순자산, 색 = 액티브 여부
- **내 점 강조**
- 점 클릭 → 참가자 상세

## 10. 대회 결과 (`/contests/<id>/result/`)

대회 종료 후에만 접근 가능.

| 섹션 | 내용 |
|---|---|
| 최종 순위표 | 순위 · 별칭 · 최종 수익률 · 수익 점수 · 관리 점수 · **최종 점수** · **등급** |
| 시상 | 대회 설정에 따라 |
| 통계 | 평균 수익률 · 최고/최저 · 참가자 분포 히스토그램 |
| **회고 자료** | 가장 많이 담긴 종목 · 가장 수익이 큰 종목 · 전략 유형 분포 |

> **회고 자료가 동아리 대회의 핵심 가치다.** 순위만 발표하고 끝나면 배우는 게 없다.
