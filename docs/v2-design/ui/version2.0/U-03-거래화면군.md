### 2.2 v1.0 대비 변경

| 항목 | 변경 |

## 3. 코인 연습 (`/practice/crypto/`)

### 3.1 레이아웃

```
┌─ 모드 배지: [코인 연습]  현금 · 순자산 ────────────────────┐
├──────────────┬────────────────────┬─────────────────┤
│ 마켓 리스트    │  차트               │  주문 패널        │
│ (WebSocket)   │  (Lightweight)     │  · 원화 금액 입력  │
│ [KRW][⭐]     │                    │  · 수량 자동 산출  │
│               ├────────────────────┤  · [물타기 시뮬]  │
│ 🔍 검색        │  국내 4사 시세 비교   │                 │
│               │  업비트·빗썸·코인원·코빗│                 │
│ 🏆 거래대금     │  (실패는 - 표시)     │                 │
│    TOP 10 ★   │                    │                 │
├──────────────┴────────────────────┴─────────────────┤
│ 보유 코인 테이블 (실시간 평가)                             │
└────────────────────────────────────────────────────┘
```

★ = 코인 랭킹 재정의 (KRW 마켓 거래대금 기준) — 결함 D-3 해소

### 3.2 실시간 처리

- 시세는 **브라우저 ↔ 업비트 WebSocket 직접 연결** (서버 부하 0)
- 보유 평가금액·수익률은 WebSocket 값으로 **클라이언트에서 계산** (v1.0 방식 유지)
- 주문·잔고는 서버 권위
