## 3. 개념으로만 가져올 것

### 3.1 Bronze → Silver → Gold (crawling-lab)

우리는 이미 **같은 모양**을 다르게 부르고 있다.

| crawling-lab | 우리 | 비고 |
|---|---|---|
| Bronze — 원본 그대로 JSONL | `data/raw/` (gitignore · 909파일) | 🔒 우리 것은 **저장소를 떠나지 않는다**(제약 10) |
| Silver — 정제·표준화 | `sector_daily` · `market_daily` | |
| Gold — 분석용 집계 | `score_daily` + HF 게시 | |

즉 **새로 배울 구조가 아니라 우리 구조가 이미 표준형임을 확인한 것**이다.
차이는 저장소다 — 그쪽은 MinIO(S3), 우리는 로컬 parquet + HF private. 제약 4 때문에 그대로 둔다.

### 3.2 RAG 에이전트 구조 (th07) — **#10 Layer B 에 직접 닿는다**

`th07/lecture/app/services/` 에 `orchestrator.py` · `context_router.py` · `tool_registry.py` ·
`tool_executor.py` · `hybrid_search.py` · `rag_service.py` · `llm_service.py` ·
`session_memory.py` · `long_term_memory_service.py` 가 있다.

우리 `dashboard/agent/`(ADR-SC-0013)는 **LLM 없이** 같은 자리를 규칙으로 채웠다 —
`intent.py`(라우팅) · `inventory.py`(근거 수집) · `compose.py`(조립) · `guard.py`(대조).
th07 과 **층이 거의 일치한다.**

| th07 | 우리 | 다른 점 |
|---|---|---|
| `context_router.py` | `agent/intent.py` | 우리는 **문자 n-gram**. 임베딩은 "왜 반도체 안 사?" 를 못 거절했다(Z3) |
| `tool_registry` · `tool_executor` | `agent/inventory.py` | 우리는 도구가 아니라 **장부**를 채운다 |
| `llm_service.py` | **없다** | 🔴 제약 1·2 |
| *(없음)* | **`agent/guard.py`** | 🔴 th07 에는 **출력 검증 층이 없다.** 우리의 핵심이 그쪽엔 없다 |

**#10 Layer B 를 볼 때의 결론** — th07 은 "LLM 을 어디에 끼우나" 의 참고가 되지만,
🔒 **신호 경로 밖**(팀 글 요약)이어야 하고 `guard` 를 통과하지 못하는 문장은 그리지 않는
우리 규율이 그대로 살아 있어야 한다. th07 에는 그 층이 없으므로 **구조를 베끼면 안 된다.**

### 3.3 영업일 달력 (th07 `market_calendar_data.py`, 74줄)

우리는 영업일을 **받은 데이터에서** 세고 있다(`bas_dd` 축). 별도 달력 테이블을 두지 않는다.

그때 무엇이 사실인지 판정할 근거가 둘이 된다.
